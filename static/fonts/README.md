# Font

Semua font di folder ini memakai SIL Open Font License 1.1. Teks lisensinya ada di samping file font, dan lisensi itu wajib ikut saat font didistribusikan.

| File | Font | Sumber | Lisensi |
| --- | --- | --- | --- |
| `Montserrat-Variable.woff2` | Montserrat, semua weight, subset Latin | `@fontsource-variable/montserrat` 5.3.0 | `Montserrat-OFL.txt` |
| `Montserrat-Light.woff2`, `Montserrat-Medium.woff2`, `Montserrat-SemiBold.woff2` | Montserrat statis | Masuk di commit `05b5ada`, sumber unduhannya tidak tercatat | `Montserrat-OFL.txt` |
| `JetBrainsMono-Regular.woff2`, `JetBrainsMono-Medium.woff2`, `JetBrainsMono-SemiBold.woff2` | JetBrains Mono statis | Masuk di commit `05b5ada`, sumber unduhannya tidak tercatat | `JetBrainsMono-OFL.txt` |

Proyek asalnya: [Montserrat](https://github.com/JulietaUla/Montserrat) dan [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).
