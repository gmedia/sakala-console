# Font

Semua font di folder ini memakai SIL Open Font License 1.1. Teks lisensinya ada di samping file font, dan lisensi itu wajib ikut saat font didistribusikan.

| File | Dipakai untuk | Sumber | Lisensi |
| --- | --- | --- | --- |
| `Inter-Variable.woff2` | Teks baca, semua weight, subset Latin | `@fontsource-variable/inter` 5.3.0 | `Inter-OFL.txt` |
| `Montserrat-Variable.woff2` | Judul dan display, semua weight, subset Latin | `@fontsource-variable/montserrat` 5.3.0 | `Montserrat-OFL.txt` |
| `JetBrainsMono-Variable.woff2` | Kode, log, nama teknis, semua weight, subset Latin | `@fontsource-variable/jetbrains-mono` 5.3.0 | `JetBrainsMono-OFL.txt` |

Proyek asalnya: [Inter](https://github.com/rsms/inter), [Montserrat](https://github.com/JulietaUla/Montserrat), dan [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).
